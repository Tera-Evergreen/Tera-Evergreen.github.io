Who uses this app

Hermes Agents (gum) is a private, personal tool. Its only users are Tera Evergreen's own Google accounts. It is not available to anyone else.

What data it accesses

When Tera asks, the app reads and organizes data in Tera's own Google accounts: Gmail, Google Calendar, Google Drive, Docs, Sheets, Slides, Forms, Tasks, Contacts, Google Meet, Apps Script, Search Console and YouTube. It only acts on Tera's own data.

Where the data goes

  • Sign-in tokens are stored only on Tera's own computer, in the Windows credential store.
  • Data is processed on Tera's computer by Tera's own assistants. It is not sold, shared, rented or used for advertising.
  • Nothing is sent to anyone other than Google and the AI services Tera personally uses to run the assistants.

Changes and deletion

Tera can remove the app's access at any time at myaccount.google.com/permissions. Removing access stops all use of the data.

Google API Services User Data Policy

This app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
