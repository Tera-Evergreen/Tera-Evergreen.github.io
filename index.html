Hermes Agents (gum)

Hermes Agents (gum) is a private tool used only by Tera Evergreen. It lets Tera's own AI assistants, running on Tera's own computer, read and organize Tera's own Google account data (mail, calendar, files and YouTube channel) when Tera asks them to.

It is not offered to the public, and no one else can sign in to it.
